# TileLoom


已部署在[这里](https://tile.qyinv.icu)，无需构建即可使用。

TileLoom 是一个纯前端的平面设计工具，一个瓷砖像素画预览器。
上传像素画或使用内置示例后，需要对图片进行预处理。你可以在原图上拖拽框出一个区域，或直接输入宽度 X 和高度 Y，使得原图中的每 X × Y 个像素会*取平均色*合成一个新像素。对于像素画，保持 1 × 1 即可，而真实图片可以借此缩小成合适的瓷砖数量。预处理步骤中设置的内容之后可随时调整。
完成预处理步骤后，可以调整瓷砖尺寸、边框颜色与宽度、圆角、缝隙宽度和缝隙颜色，即时查看墙面效果并保存为 SVG。

### 开发&构建

确保已安装 Node.js 20+ 和 pnpm，然后在项目目录执行：

```bash
pnpm install
pnpm dev
```

打开终端输出的本地地址即可使用。生产构建可以运行 `pnpm build`。
